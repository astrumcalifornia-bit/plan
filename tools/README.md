# a5_to_a4.py — двухсторонний макет A4 из страниц A5

Складывает картинки страниц A5 по две на лист A4 (лист лежит горизонтально)
и отдаёт готовый к печати PDF: лицо листа 1, оборот листа 1, лицо листа 2 и так далее.

## Установка

```bash
pip install pillow img2pdf
```

## Использование

```bash
# брошюра на скрепку: печатаем, складываем стопку пополам, сшиваем
python3 tools/a5_to_a4.py pages/ -o booklet.pdf --mode booklet

# разрезать и сложить: печатаем, режем пачку пополам, правую стопку под левую
python3 tools/a5_to_a4.py pages/ -o print.pdf --mode simple

# явный порядок страниц вместо папки
python3 tools/a5_to_a4.py cover.jpg p1.jpg p2.jpg back.jpg -o print.pdf
```

Порядок страниц из папки берётся по имени файла с натуральной сортировкой,
то есть `page-2.png` идёт раньше `page-10.png`.

## Режимы

| `--mode`  | Что делать после печати | Порядок страниц на листах (8 страниц) |
|-----------|-------------------------|----------------------------------------|
| `booklet` | Сложить стопку пополам  | `8‑1 / 2‑7`, `6‑3 / 4‑5` |
| `simple`  | Разрезать пополам, правую стопку под левую | `1‑5 / 6‑2`, `3‑7 / 8‑4` |

Количество страниц добивается пустыми до кратности четырём.

## Переворот при двусторонней печати

Макет горизонтальный, поэтому по умолчанию он рассчитан на переворот
**по короткой стороне** (`--flip short`) — в драйвере это «Двусторонняя печать,
переплёт по короткой стороне» / «Flip on short edge».

Если принтер умеет только переворот по длинной стороне, соберите файл
с `--flip long` — обороты будут повёрнуты на 180°, и страницы встанут ровно.
Проверить дёшево: напечатать первый лист на черновике.

## Остальные ключи

| Ключ | Зачем |
|------|-------|
| `--fit contain\|cover` | `contain` — страница целиком с белыми полями (по умолчанию), `cover` — заполнить половину листа с обрезкой краёв |
| `--dpi 300` | разрешение растра |
| `--margin 5` | поле по краю листа, мм (для принтеров без печати в край) |
| `--gutter 3` | отступ от линии сгиба, мм |
| `--fold-line` | пунктир по линии сгиба/реза |
| `--crop-marks` | метки реза по краям листа |
| `--format png\|jpeg` | как вложить растр: `png` без потерь, `jpeg` компактнее |
| `--preview DIR` | выгрузить листы картинками, чтобы посмотреть до печати |

Полная справка: `python3 tools/a5_to_a4.py --help`.
