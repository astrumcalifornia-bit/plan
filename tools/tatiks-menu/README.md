# Подготовка меню Tatik's к печати

Скрипты под конкретный макет: 4 страницы A5 (1053×1494 px), сложенный пополам лист A4.
Координаты полос и QR прописаны константами — для другого макета их надо перемерить.

Порядок чтения: обложка (`2.png`) → `3.png` → `4.png` → задняя обложка (`1.png`).
Лицевая сторона листа `1 | 2`, внутренняя `3 | 4`.

## fix_borders.py

Сводит орнаментальный бордюр соседних страниц в один непрерывный.
В исходниках полосы расходились по трём параметрам:

| Страница | Высота верхней полосы | Высота нижней | Период узора |
|---|---|---|---|
| `1.png` | 84 px | 60 px | 66 px |
| `2.png` | 75 px | 68 px | 62 px |
| `3.png` | 88 px | 86 px | 64 px |
| `4.png` | 101 px | 95 px | ~70 px |

Что делает:

1. приводит тон бумаги всех страниц к общему (`1.png` был светлее остальных на 7–11 единиц);
2. стирает старые полосы, закрашивая кремом из чистой области той же страницы, с растушёвкой края;
3. берёт полосу с обложки как эталон, определяет период с точностью до доли пикселя
   и замащивает ею весь лист A4 целиком — за счёт этого узор идёт через сгиб без разрыва;
4. подбирает плитку так, чтобы целое число повторов легло точно в ширину листа
   (правка масштаба вышла 0.1 % и 0.7 % — не видна).

Итог: `fixed/p1-cover.png`, `p2-inside-left.png`, `p3-inside-right.png`, `p4-back.png`.

## replace_qr.py

Меняет QR на обложке, сохраняя белую подложку с мягким градиентом:
восстанавливает подложку сглаживанием по светлым пикселям (старые модули игнорируются),
затем накладывает новый QR по альфе. Новый код — `https://lnk.at/tatikvareniki`,
вписан ровно в габарит старого (188×188 px), читаемость проверена уже с готового листа.

## Сборка

```bash
python3 fix_borders.py
python3 replace_qr.py
python3 ../a5_to_a4.py fixed -o tatiks-a4.pdf --mode booklet --flip long --fit cover --dpi 180
```

Исходники ожидаются в `real/1.png` … `real/4.png`.
