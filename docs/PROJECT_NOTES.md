## Структура сайта (деплой из репозитория через .cpanel.yml)

| URL | Файл в репо | Что это |
|---|---|---|
| / | landing/index.html | RU лендинг, вариант A |
| /b/ | landing/b/index.html | RU лендинг, вариант B (A/B-тест) |
| /en/, /en/b/ | landing/en/..., landing/en/b/... | EN версии A и B |
| /go/ | go/index.html | агрессивный лендинг «для горящих» |
| /privacy/ | privacy/index.html | политика конфиденциальности |

Деплой: cPanel → Git Version Control → Update from Remote → Deploy HEAD Commit.
.cpanel.yml копирует файлы в /home/xkryolap/public_html и /home/xkryolap/usbusinesslaunch.com.

Технически лендинги A/B — «bundled page»: статический текст-фолбэк (#nojs) в начале
файла + огромный manifest + template (JSON в <script type="__bundler/template">).
Правки шаблона: json.loads → правка строки → json.dumps(ensure_ascii=False).replace('</','<\\u002F').
